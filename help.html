Complete Guide & Documentation

🚀 Getting Started

1 Install the Extension: Load the extension in Chrome.
2 Get an API Key: Pick a provider and create a key.
3 Open WhatsApp Web: Navigate to web.whatsapp.com and scan the QR code to log in.
4 Configure Settings: Click the floating AI button and go to Settings.

📖 How to Use

Exporting Conversations

  1. Open any WhatsApp conversation
  2. Click the green floating AI button
  3. Select "Export Conversation"
  4. The conversation will be downloaded as a text file

Generating AI Responses

  1. Make sure you've configured a provider and its API key
  2. Open any WhatsApp conversation
  3. Click the floating AI button
  4. Select "Generate AI Response"
  5. Wait for the AI to analyze the conversation
  6. Copy the response or insert it directly into the chat

Message Detection

The extension automatically detects both incoming and outgoing messages using these CSS selectors:

Incoming messages: .message-in
Outgoing messages: .message-out
Message containers: [data-testid="msg-container"]

🌐 Language

Two separate settings, both in the AI button → Settings dialog.

  • Interface Language: The language of the extension's own menus, dialogs and messages.
  • Reply Language: The language the AI writes its drafts in.

The two are independent.

⚙️ Configuration

API Key Setup

  1. Create a key at your provider, from the links above
  2. In WhatsApp Web, click the AI button → Settings
  3. Choose the provider from the dropdown
  4. Paste your API key
  5. Optionally set a model
  6. Save, then use "Test Connection" to verify it works

Custom and local endpoints

Chrome only lets the extension reach the hosts listed in its manifest.

Running Ollama? Start it with OLLAMA_ORIGINS=*.

⚠️ Important: Keep your API key secure and never share it publicly.

🔧 Technical Details

Message Extraction

The extension uses multiple selectors to reliably extract messages:

  • .selectable-text - Main message text
  • [data-testid="conversation-text"] - Alternative text selector
  • [data-testid="msg-time"] - Message timestamps
  • [data-pre-plain-text] - Sender information for group chats

AI Integration

Whichever provider you pick is called with the same generation settings:

Provider: your choice (see above)
Model: the provider's default, or whatever you set
Temperature: 0.7 (balanced creativity)
Max Output Tokens: 1024
Context: up to the 100 most recent messages

Requests are made from the extension's background service worker.

🐛 Troubleshooting

Extension Not Working

  • Refresh the WhatsApp Web page
  • Check if the extension is enabled in chrome://extensions/
  • Make sure you're on web.whatsapp.com

AI Responses Not Generating

  • Verify the API key matches the provider selected in Settings
  • Press "Test Connection" in Settings
  • A 404 usually means the model name is wrong
  • For a custom endpoint, grant access from the extension popup
  • Check your internet connection and rate limits

Messages Not Extracting

  • Make sure the conversation is fully loaded
  • Scroll up to load older messages if needed
  • Refresh the page and try again

Replies Come Back in the Wrong Language

  • Set Reply Language in Settings rather than in the System Instructions box
  • Smaller models are weaker at languages other than English

🔒 Privacy & Security

  • All message processing happens locally in your browser
  • API keys are stored in Chrome's sync storage, one per provider
  • Conversations are only sent to the provider you selected
  • No data is stored on external servers
  • Extension only works on web.whatsapp.com for security
